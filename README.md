## 📋 Overview

This repository contains a comprehensive, 26-topic practical lab guide for System and Network Administration. It is designed for BS-IT students to perform hands-on labs using **VirtualBox**, **Windows Server**, **Ubuntu Linux**, and **Cisco Packet Tracer**.

---

## ✨ Key Topics Covered

* **Virtualization:** Setting up Windows Server and Linux VMs on VirtualBox.
* **Network Setup:** Configuring NAT and Host-Only adapters, Static IPs.
* **Active Directory (AD DS):** Installing AD, promoting a Domain Controller, creating OUs, Users, and Groups.
* **Linux Administration:** System verification, boot management, process control, and bash scripting.
* **Security & Services:** iptables firewall, SSH hardening, Apache Web Server, DNS, DHCP, FTP, NFS, and Samba.
* **Cisco Networking:** Router and Switch configuration, VLANs, WAN setup, Static & Dynamic Routing (RIP, IGRP), and ACLs.
